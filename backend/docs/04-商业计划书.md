# 上饶家谱数字化项目商业计划书

**项目代号：饶信谱脉**
**版本：V1.0｜2026年9月**
**适用范围：上饶市广信区（原上饶县）全域，可复制至上饶市 12 个县市区**

---

## 摘要：一页看懂

**做什么**：把广信区（原上饶县）各家族的老家谱全部数字化，建成"上饶姓氏谱牒数据库"，在此之上做微信小程序，让年轻人用手机查自己的根、看自己的家族树，并和家人一起"接力"把家谱续写下去。

**为什么现在做**：
- 70 岁以上老人是唯一还记得家族口述史的一代，这批人正在快速离世，谱源窗口期只有 5—8 年；
- 广信区常住人口 74.37 万（2025 年末），户籍 86.65 万，净流出 12 万人，年轻人散在长三角和川渝——**越离散，寻根需求越强**；
- 年轻人寻根已成显性需求：小红书 #我的家庭简史 话题浏览量 1.38 亿、参与 54.7 万人，抖音"寻根"相关话题年播放量超 30 亿次；
- 政策有窗口：国家档案局 2026 年启动 AI 应用试点，多地档案馆（浙江仙居、山东潍坊、河南平顶山）已开展族谱数字化，厦门已建"海峡两岸族谱数据平台"。

**商业模式（C 端优先）**：
用 B 端（宗亲会、祠堂理事会、档案馆）免费换谱源 → 用谱源做 C 端免费查询获客 → 在情感峰值时刻（清明、冬至、春节、长者辞世）向个人和家庭收增值费 → 用实体印刷和家乡文创赚高客单。

**核心杀手锏**：**接力修谱**。一个人生成家族邀请码 → 发到家族微信群 → 每位亲属只填自己那一段 → 系统自动合并成完整家族树。把"修谱永远是两三个人的事"变成"全家一起干的事"。

**收入目标**：第 1 年（谱源期）以品牌和谱源积累为主，收入 15—25 万元；第 2 年 80—150 万元；第 3 年 300—500 万元，C 端收入占比目标 55% 以上。

**最大的坑**：家谱是**群体决策**品类，单个年轻人不会为一个"家谱 App"付 99 元。所以 C 端优先的关键不是把 App 做得好玩，而是**把付费点卡在情绪最浓的那几天**，并且**让付钱的人不用干活**。

3. **城镇化率 63.87% 且每年提高 1.3 个百分点**，意味着乡村聚族而居的形态正在瓦解，祠堂、宗谱的"物理载体"功能持续弱化——**数字化是唯一能留住它的方式**。

### 1.3 需求侧：年轻人已经在寻根了

| 平台/现象 | 数据 |
|---|---|
| 小红书 #我的家庭简史 | 54.7 万人参与，1.38 亿次浏览，春节一度成为热门话题 |
| 小红书 #写个我家的故事 | 同上话题池 |
| 小红书 #家史 话题 | 327.5 万浏览与互动 |
| 家庭史创作者年龄分布 | 33—40 岁占 23%、41 岁以上 20.1%、28—32 岁 19.6%、23—27 岁 18.1% |
| 创作者性别 | **61.1% 为女性**（传统家谱里常无名的女性，是家史叙事的绝对主力） |
| 数字化老物件 | 31500 件以上（含日记、老照片、家谱、账本） |
| 抖音/小红书 #寻根 话题 | 年播放量 > 30 亿次，90 后/00 后占比 58% |
| "大槐树迁徙"话题 | 视频播放量突破 8 亿次 |
| AI 歌曲《寻根问祖之歌》 | 一个月内全球 5262 万次播放，**纯靠宗亲群私域传播，无明星无投放**；私域流量是公域的 1.7—1.9 倍 |
| 某电商平台"电子家谱"搜索量 | 现象级国风短片走红后暴涨 **470%** |

**三个必须记住的洞察**：

1. **主力人群是 33—40 岁，不是 00 后**。这个年龄段的人刚生了孩子、开始面对长辈衰老、事业初成有支付能力。产品不能做得太"二次元"，要做得"体面"。
2. **女性是家史叙事的主力（61.1%）**。传统家谱里女性常常只有姓氏没有名字，这是家谱数字化的一个巨大价值缺口和情绪引爆点——**"让你的妈妈、外婆、奶奶，在家谱里有名字"**，这是一句能打动人的文案。
3. **私域传播效率是公域的 1.7—1.9 倍**。这个品类的传播战场在**家族微信群**，不在抖音信息流。所有推广机制都要围绕"让家族群自己转起来"设计。

### 1.4 竞争格局与我们的位置

| 竞品 | 模式 | 优势 | 弱点（我们的机会） |
|---|---|---|---|
| **族谱网**（zupu.cn） | 全国平台 + 加盟服务商（县级） | 老谱库（名门述源 22 万册、覆盖 500+ 姓氏）、专利排版、加盟体系成熟 | 全国通吃，**县域深耕不足**；加盟商利益分配矛盾；产品偏"修谱工具"不偏"C 端体验" |
| **名门修谱**（大商帮，新三板 832557） | 修谱 SaaS + 县级分公司 | 10 年经验、3 万家族、2000 万条数据、17 家县级分公司、1300 名注册修谱师 | 重线下服务、轻 C 端产品；小程序体验偏传统 |
| **寻根通** | 谱牒数据库 | 收录明清家谱 1200 余万卷，数字化率 89% | 偏机构与学术，无 C 端产品 |
| **浙里/各地档案馆** | 公益数字化 | 官方背书、数据权威 | 不商业化、不做 C 端体验、不运营 |

**我们的差异化定位**：

> **不做全国最大的家谱平台，做"上饶人自己的谱"。**
> 全国平台的弱点在于它必须同时对 2800 个县负责，所以它对任何一个县都只能做到"够用"。而我们可以把广信区 23 个乡镇、22 万户、"谁家祖上从福建哪个村迁来的"这件事，做到**比当地老人还清楚**。

**三个战术差异点**：
1. **谱源先行**：先花 6—12 个月把谱源（老谱扫描件+OCR 数据）拿到手，这是唯一的护城河。产品可以抄，谱源抄不了。
2. **C 端体验优先**：全国平台的小程序是"修谱工具"，我们要做的是"**给年轻人看的家族故事产品**"。
3. **官方背书**：与区档案馆、文旅局、乡镇文化站共建，把项目定位为"**地方文献抢救性数字化**"，而不是"商业修谱"。

### 1.5 市场规模测算

采用"红丁计费"这一行业通行口径（传统修谱按男丁收费，现多按人口）。

**保守测算（仅广信区）**：
- 户籍人口 86.65 万，扣除 18 岁以下约 20%，可得参与人口约 **69 万人**；
- 家谱数字化的渗透率即使只有 **15%**，即 **10.4 万人**；
- 人均生命周期消费（数字化服务 + 印刷 + 增值）保守按 **80 元**计；
- **可寻址市场（TAM）≈ 830 万元**

**乐观测算（C 端增值打开后）**：
- 10.4 万付费用户，人均 **300 元**（含实体家谱印刷、祖源报告、影像服务）；
- **TAM ≈ 3120 万元**

**叠加 B/G 端**：
- 200 个家族整族数字化服务，族均 1.5 万元 = 300 万元
- 政府/档案馆项目 3 年 3 个项目 = 100—200 万元
- **广信区总体可寻址市场 ≈ 4000 万元**

**可复制性**：上饶市下辖 3 区 8 县 1 市，户籍人口约 780 万（约为广信区的 9 倍）。
- 全市 TAM ≈ **3.6 亿元**
- 江西省 TAM ≈ **30 亿元**

> 参考：族谱网公开测算"一个县 100 万人，每人收 50 元修谱费，就是 5000 万保守市场规模"。我们的测算口径比它保守（人均 80 元含全生命周期），这是有意为之。

### 2.1 产品架构：三层结构

│  整族数字化 · 数字祠堂 · 家族SaaS · 纸谱印刷          │
└─────────────────────────────────────────────────────┘
                        ↑ 提供谱源
┌─────────────────────────────────────────────────────┐
│  第二层：个人层（C端付费，做利润）                    │

└─────────────────────────────────────────────────────┘
                        ↑ 提供体验
┌─────────────────────────────────────────────────────┐

**关键判断**：第一层必须**永久免费且不用登录就能看到东西**。因为家谱的首次访问绝大多数来自"别人分享的链接"，多一步登录就损失一半用户。

### 2.3 核心机制详解：接力修谱（Why this wins）

**行业公认的最大痛点**：
> "很多家族网站热闹了头几个月，随后便陷入沉寂——录入数据的永远是那两三个人，其他人偶尔登录看一眼，从不贡献内容。"（族谱网行业观察）

**为什么会这样**？传统修谱是**中心化任务**：让谱师或热心人挨个收集。信息采集是"求人办事"，社会性成本极高。

**接力修谱的设计逻辑**——把"求人收集"变成"自愿认领"：

1. **建树**：任意家族成员创建家族树，填入自己 + 父母（3 分钟完成，零负担）
2. **生成邀请二维码**：系统生成一个带唯一标识的入族链接
3. **发到家族群**：一句话文案自动生成，例如——
   > "我们家的家谱树做好了，二叔你点进去填一下爷爷那一支吧，就两分钟。"
4. **各房认领**：每个人进来只做一件事——**补齐自己这个小家庭的那一格**。不知道自己爷爷的生年？可以选"我不知道"，系统标记为待补充，不阻塞流程。
5. **自动合并**：系统按姓名 + 辈分 + 父系关系做合并去重，冲突时提示"你和三婶填的不一致，谁改一下"
6. **长辈催办机制（关键）**：当长辈看到自己已经被"接"进树里、名字已经出现，会产生强烈的确认冲动——**他们会主动去催下一代填**。这是自然发生的组织力，不需要我们做运营。

**为什么这个机制能破局**：
- **任务颗粒度极小**：从"整理全族"降到"填我这一格"
- **社会性成本为负**：不是求人办事，而是"这是我们家的树，你也有份"
- **自带组织力**：不需要我们维护秩序，家族内部的长幼秩序会自然完成催办
- **数据质量可控**：同一支系由多人交叉填写，错误可以被发现

**配套的激励设计**：
- **贡献值 / 谱丁分**：每补充一条信息得积分，积分可兑换实体家谱折扣券、家族树海报、姓氏文创
- **可见的贡献署名**：字段显示"由 XXX 提供"，让贡献被看见
- **家族榜**：显示本族贡献榜，自然形成家族内部的良性竞争

### 2.4 技术路线建议（结合现有能力）

| 层 | 建议 | 说明 |
|---|---|---|
| 前端 | 微信小程序原生 | 已具备能力；小程序免下载、微信实名、可一键分享家族群，是本品类最优载体 |
| 后端 | Node.js / Python + MySQL | 已有的导表与脚本能力可直接复用 |
| 图谱关系 | MySQL 递归 CTE 起步，规模上来后引入 Neo4j | 家族树查询是典型的图问题，但早期用递归 CTE 足够，不要过度设计 |
| 老谱识别 | 多模态大模型 + 谱牒专用后处理 | 现有 OCR 方案对手写繁体谱牒准确率不足；行业已能做到 92% 字段自动入库，需要用"人名 + 辈分 + 生卒"的表格结构做约束校验 |
| 合并去重 | 规则引擎 + 人工复核队列 | 姓名消歧（同名不同人）是核心难点，必须有"待确认"状态而非自动合并 |
| 隐私 | 字段级权限分级 + 活人信息单独授权 | 见第六章 |
| 存储 | 对象存储 + CDN，原始扫描件冷备 | 高清谱牒扫描件体积大，热数据与冷数据要分开 |

**一句话**：技术不是这个项目的瓶颈，**谱源和信任才是**。所以前期技术投入建议控制在总资源的 30% 以内，70% 用于谱源获取和线下关系。

## 四、推广方案（执行级）

### 4.1 总体节奏：三个阶段

```
阶段一 谱源攻坚期        阶段二 家族扩散期        阶段三 C端破圈期
(0—3个月)               (3—9个月)               (9—24个月)
                                              ┌──────────────┐
   找谱        ──►        找家族      ──►      │   找个人     │
                                              └──────────────┘
目标: 20个姓氏谱源      目标: 200家族入驻      目标: 20万注册用户
      5个标杆家族             10万条人口数据          40%付费转化
```

**阶段之间的递进逻辑**：
- 没有谱源，小程序是空壳子 → 所以必须先攻谱源
- 没有家族组织，谱源录不进系统 → 所以第二步找家族
- 没有个人用户，变现无从谈起 → 所以第三步做 C 端

**核心原则：C 端优先 ≠ C 端第一步。** C 端优先指的是**最终的利润来源和产品重心在 C 端**，但**冷启动必须从 B 端（族）切入**，因为谱源掌握在族里，不在个人手里。这是本行业最重要的常识。

### 4.2 阶段一：谱源攻坚期（第 1—3 月）

**目标**：拿下 20 个姓氏的谱源，完成 5 个标杆家族的完整数字化，跑通"采集 → 上树 → 交付"流程。

**核心打法：免费数字化置换**

> **"您的族谱，我们免费帮您扫描、修图、做成电子的，还能一键打印。我们只要一样东西：允许我们把谱里的世系信息收录进'上饶姓氏谱牒数据库'，供族人免费查询。"**

这个提议对家族几乎没有拒绝的理由：
- 老谱多为孤本，虫蛀、霉变、火灾风险极高，家族其实一直担心
- 免费获得一套电子版 + 修复版 + 可印刷版，价值数千元
- 唯一让渡的是"可查询"，这本身就是族谱的初衷（收族）

**谱源获取的具体渠道与 SOP**

| 渠道 | 目标对象 | 接触方式 | 成功率预估 |
|---|---|---|---|
| **区档案馆** | 馆藏族谱（如道光年间彭城堂刘氏族谱） | 以"共建地方文献数字化"名义合作，提供免费数字化服务换取扫描权与联合署名 | 高（需 1—2 个月对接） |
| **乡镇文化站** | 23 个乡镇文化站站长 | 逐个拜访，站长是本地家族情况的最佳信息源 | 高 |
| **祠堂理事会** | 有实体祠堂的宗族 | 直接上门，祠堂都有理事会或管理小组 | 高 |
| **族中长者** | 退休教师、老支书、老兵、老谱保管人 | 通过文化站或熟人引荐 | 中高 |
| **地方文史圈** | 地方志办公室、文史爱好者、族谱收藏者 | 加入本地文史微信群、参加宗亲活动 | 中 |
| **已故族谱的数字化线索** | 已有家族做过简单电子版的 | 网络搜索 + 宗亲群打听 | 中 |

**地推 SOP（标准作业流程）**

```
第 1 步：情报准备
  · 确认这个姓氏在广信区的分布乡镇、祠堂位置、理事会负责人
  · 查清该族源流（从福建/河南/徽州何时迁入）
  · 准备该姓的"预热页"：用已有公开资料做一张 demo 家族树

第 2 步：首次接触（关键：先给价值，再提要求）
  · 带上打印好的族谱修复样张（对比图：模糊原图 vs 高清修复版）
  · 现场用手机打开小程序，让长者**亲眼看到自己的名字出现在家族树里**
  · 一句话核心话术：
    "X 老，我们做的是上饶家族谱牒的数字化保存。
     您这本谱，我们免费帮您做成电子的，虫子咬都不怕，
     以后在外面的子孙拿手机就能查。
     我们只有一个请求，就是让谱里的世系能进我们的数据库，
     让散在外地的族人能查到自己的根。"

第 3 步：现场共识
  · 立刻做一本样谱（用平板现场扫描 5 页 + AI 修复）
  · 让长者确认效果，这是信任建立的决定性瞬间

第 4 步：正式合作
  · 签署《谱牒数字化合作与数据授权书》
  · 明确：纸质原本立即归还、数据用途范围、署名方式、家族撤回权
  · 拍合作合影（这是最好的后续传播素材）

第 5 步：交付与激活
  · 30 个工作日内交付：高清电子谱 + 可检索版本 + 数字家族树
  · 交付时同步教族中 1—2 名年轻人使用小程序，发展为"家族大使"
  · 交付仪式尽量做得有仪式感（祠堂内、有长者见证、拍照记录）
```

**阶段一关键动作清单**

| # | 动作 | 完成标准 |
|---|---|---|
| 1 | 建立"广信区家族档案台账" | 23 个乡镇逐村梳理，记录姓氏、祠堂、有无族谱、保管人、联系方式 |
| 2 | 完成区档案馆合作协议 | 拿到至少 2 部馆藏族谱的扫描与收录授权 |
| 3 | 完成 5 个标杆家族数字化 | 每个家族都有可展示的完整家族树 |

| 5 | 签订 20 份数据授权书 | 每家一份，建立档案 |
| 6 | 拍摄 5 支"寻根"短视频 | 用标杆家族的真实故事，发布到抖音/视频号 |

### 4.3 阶段二：家族扩散期（第 3—9 月）

**目标**：200 个家族入驻，10 万条人口数据，跑通接力修谱的自传播。

**三条主线**

**主线 1：一姓一策**

不同姓氏的资源禀赋完全不同，不能用同一套打法：

| 家族类型 | 特征 | 打法 |
|---|---|---|
| 有祠堂 + 有族谱 + 有理事会 | 组织完备（如安坑龚氏、上泸余氏） | 直接对接理事会，走 B 端整族数字化，快速拿下 |
| 有族谱但无祠堂 | 文人型家族（如刘氏、朱氏） | 找族中长者与在外成功人士，走"文化传承"叙事 |
| 有祠堂但无族谱 | 需要通过口述重建 | 做口述史采集，把过程本身做成内容 |
| 无祠堂无族谱但聚居 | 新兴聚落 | 从"姓氏分布地图"切入，做轻量家谱 |
| 名门后裔（朱氏、刘氏） | 天然话题性 | 做标杆内容，优先拍摄纪录片式短视频 |

**主线 2：家族大使制度**

在每个合作的家族中，物色 1—2 名"家族大使"（优先选：返乡青年、退休教师、村小教师、宗亲会年轻人）。

**大使激励设计**：
- **现金提成**：本族 C 端与 B 端收入的 15—25%
- **荣誉体系**：颁发"上饶家谱数字化推广使者"证书，公示在家族树页面与祠堂
- **积分权益**：贡献值可兑换实体家谱、文创、家族树海报
- **成长路径**：优秀者培养为付费修谱师（¥1,980 培训认证），形成职业出口
- **署名权**：在数字家谱的"修谱纪事"中永久署名——**对很多人来说，这一条的吸引力超过现金**

**主线 3：节点营销（极其关键）**

家谱消费高度依赖时间节点，必须把所有营销资源压在三个窗口：

| 节点 | 时间 | 用户心理 | 主打产品 | 动作 |
|---|---|---|---|---|
| **清明祭祖** | 4 月 1—15 日 | 返乡、扫墓、家族聚会、怀念先人 | 云祭扫、口述史录制、家族树海报、老谱修复 | 提前 3 周在家族群预热；清明当天在祠堂设"数字扫谱"服务点；现场帮老人把名字录进树 |
| **冬至祭祖** | 12 月 20—25 日 | 宗族大祭、修谱会议的旺季 | 整族数字化、纸谱印刷、家族数字馆 | 配合祠堂祭祖仪式做发布；借机召开家族代表会议推进整族签约 |
| **春节返乡** | 1 月下旬—2 月中旬 | 全员返乡、走亲访友、给长辈送礼 | 个人数字家谱、文创礼盒、会员 | 短视频集中投放；"给爸妈做一本家谱"作为年货新选择；春节主题营销（参考小红书"家庭简史"成为文化年俗的现象） |

**补充节点**：中秋（家族团圆）、老人寿宴、家族年会、高考放榜后（送族中子弟）、新生儿满月（录入新丁）。

**阶段二执行节奏表**

| 月份 | 重点 | 具体动作 |
|---|---|---|
| 第 3—4 月 | 冲刺清明 | 全部资源压清明：祠堂服务点、短视频集中发布、5 场家族见面会 |
| 第 5—6 月 | 转化沉淀 | 消化清明线索；家族大使招募与培训；产品迭代（接力修谱上线） |
| 第 7—8 月 | 内容攻坚 | 制作"上饶姓氏迁徙地图"系列内容；暑期大学生返乡实习计划（做采集志愿者） |
| 第 9 月 | 冲刺冬至 | 对接各祠堂冬至祭祖筹备；推进整族签约 |

### 4.4 阶段三：C 端破圈期（第 9—24 月）

**目标**：20 万注册用户，付费率 20%+，C 端收入占比超过 55%。

**四个增长引擎**

**引擎 1：内容矩阵（做"上饶人从哪来"这个 IP）**

| 内容形式 | 具体选题 | 平台 | 目标 |
|---|---|---|---|
| 短视频（30—60 秒） | "上饶姓 X 的，你祖上是从这里来的" + 迁徙动画 | 抖音、视频号、小红书 | 单条爆款 50 万+ 播放 |
| 中长视频（5—10 分钟） | 跟着老谱走一遍祖籍地（福建/河南/徽州实地探访） | B 站、视频号 | 建立专业形象 |
| 图文（小红书） | 老照片修复对比、家族树设计、奶奶的故事 | 小红书 | 精准触达 33—40 岁女性（家史主力人群 61.1%） |
| 口述史短片 | 广信区 90 岁以上长者访谈 | 全平台 | 情绪引爆，媒体自发报道素材 |
| 公众号/图文 | 姓氏源流考、堂号解读、字辈诗 | 微信生态 | 私域沉淀 |

**内容生产原则**：
- **主角必须是普通人**，不是名人。"一个煌固镇卖菜的老人，他的家族 600 年"比"朱熹后裔"更能打动人
- **必须有具体地名**。"从福建建宁迁到茶亭镇松坪村"胜过"从福建迁来"
- **必须留一个可转发的钩子**。比如结尾问："你家的字辈是什么？评论区告诉我"

**引擎 2：接力修谱的自然裂变**

这是最重要的增长引擎，因为它**不花推广费**。

设计要点：
1. **首次体验零成本**：扫码进来就能看到自己家的树，不需要注册就能浏览（注册只在"编辑"时要求）
2. **分享物料自动生成**：每个家族树页面都有"邀请族人一起完善"按钮，点击生成带家族名的卡片（如"茶亭镇松坪村陈氏家族树（已有 328 人）"）
3. **完成度可视化**：显示"本族已录入 62%，还差 XX 位族人"，制造完成冲动（这是行为设计里的蔡格尼克效应）
4. **认领与接力**：每人认领自己所在的分支，避免重复劳动
5. **寻亲匹配推送**：当用户在另一棵树上看到匹配的祖先名讳，主动推送"我们可能是一家人"

**裂变系数估算**：假设每个建树用户平均带来 6 名家族成员进入（家族树的天然结构），且其中 1.5 人会继续邀请自己的配偶家族 → **实际裂变系数 > 1**，理论上可实现自增长。

**引擎 3：线下触点常态化**

| 触点 | 频次 | 动作 |
|---|---|---|
| 祠堂服务点 | 每月 1 次巡回 | 现场帮族人录信息、修复老照片、打印家族树 |
| 乡镇赶集日 | 每镇每月 1 次 | 移动摊位"数字修谱服务站" |
| 家族年会 | 按需 | 赞助并现场提供数字化服务 |
| **上饶数字晒谱节** | 每年 1 次 | 自办 IP 活动。参考行业经验（晒谱节已被证明能有效聚拢宗族资源），串联各家族、媒体、政府，形成年度事件 |
| 图书馆/文化馆 | 长期 | 设"寻根查询终端"，公益服务换取曝光和政府好感 |

**引擎 4：外部合作放大**

- **与全国性谱牒平台合作**（族谱网、名门修谱、寻根通）：用我们的**县域数据**换他们的**全国老谱库查询权**，双方互补，避免正面竞争
- **与上饶籍外地商会合作**：长三角、珠三角的上饶商会是精准流量池，把"寻根"作为商会的乡情活动
- **与文旅局合作**：把家谱与古村落、祠堂、非遗打包成"寻根研学"线路（安坑龚氏祠堂是全国重点文物保护单位，上泸余氏祠堂是省级文保，松坪村是省级传统村落）
- **与媒体合作**：江西日报、上饶日报、地方融媒体对"抢救地方文脉"题材天然友好
- **海外渠道**：通过宗亲会联系海外及港台澳宗亲，这部分用户客单价最高，也最有传播意愿

## 六、合规与伦理（不可跳过的一章）

**家谱数据 = 大量活人的敏感个人信息。这一章做不好，前面所有努力可能归零。**

### 6.1 必须遵守的红线

| 事项 | 要求 |
|---|---|
| **活人信息采集** | 必须获得**单独同意**（不能和其他条款打包）。建议首次录入时由本人或直系亲属确认，并保留授权记录 |
| **未成年人** | 不满 14 周岁儿童信息属敏感个人信息，需监护人同意 |
| **女性成员** | 传统家谱常有"某氏"而无名的做法。数字化时应**主动补全女性姓名**，这既是价值主张也是合规要求 |
| **生死信息** | 卒葬、墓地位置等属于高敏感字段，默认**仅族人可见** |
| **少数民族** | 广信区有畲族等 12 个少数民族，涉民族信息需格外审慎，尊重其习俗与称谓方式 |
| **数据出境** | 若有海外宗亲使用，需评估数据出境合规路径；建议海外用户数据在境内存储，仅提供境内服务访问 |
| **删除权** | 必须提供"我要求删除我的信息"的明确通道，且真正可执行（不能只是摆设） |
| **数据安全** | 加密存储（AES-256）、访问日志、权限分级、定期备份、员工保密协议 |

### 6.2 建议的权限分级设计

| 字段 | 默认可见范围 |
|---|---|
| 姓名、辈分、世系位置 | 全族可见（活人名字建议隐藏部分字，如"陈*明"） |
| 生年、学历、职业 | 族人可见 |
| 详细住址、手机号 | **仅本人及本人授权者可见，平台默认不采集** |
| 卒葬、墓地位置 | 族人可见 |
| 婚姻、配偶 | 族人可见 |
| 敏感（身份证号、银行信息等） | **不采集** |

**核心原则：只采集"谱牒必需"的最小字段集。** 不要因为"以后可能有用"就收集手机号、身份证、住址——这些不属于家谱。

### 6.3 政策定位建议（很重要）

把项目明确定位为：

> **"上饶地方文献（谱牒）抢救性数字化项目"**

而不是"宗亲组织平台"。区别在于：
- 前者是**文化科技 + 档案服务**，可对接文旅、档案、数字经济的政策资源
- 后者容易触碰**宗族势力**的敏感边界

**具体做法**：
1. 主动向区档案馆、区文旅局报备，争取联合署名或共建身份
2. 产品不提供"宗亲组织管理""宗族议事""族规执行"等功能
3. 不谈"宗族凝聚"，谈"文化传承""乡愁记忆""青少年乡土教育"
4. 对外宣传突出"抢救""留存""数字化保护"，弱化"修谱""立谱"的宗族色彩
5. 涉台、涉侨寻根内容，参照厦门市档案馆"海峡两岸寻根寻亲服务中心"的官方范式，在官方口径下开展

### 6.4 伦理自觉

有三件事虽然合法，但需要自我约束：

1. **不要用家谱数据做婚配/健康/信贷类推断**——这会把文化项目变成数据生意
2. **不要为迎合"名门后裔"叙事而美化或虚构世系**——已有很多家族谱存在"攀附名人"的问题，平台应标注"据族谱记载"，不背书真伪
3. **不要制造家族间的对立**（比如"谁的祖上更显赫"的排行榜）——这和家谱"敬宗收族"的本意背道而驰

## 七、从广信区到全上饶：可复制路径

### 7.1 复制的三个层次

| 层次 | 时间 | 动作 |
|---|---|---|
| **县域深耕** | 第 1 年 | 广信区打透。目标是"广信区任何一个姓氏的年轻人，搜自己家的谱都能搜到" |
| **市域复制** | 第 2—3 年 | 上饶市 12 个县市区。优先顺序建议：**信州区（城区，人口密集）→ 铅山县（有 178 个行政村，谱牒资源丰富）→ 广丰区 → 玉山县（朱熹后裔集中）→ 其他** |
| **跨市外溢** | 第 3 年+ | 上饶是"江西填湖广、湖广填四川"的迁出地之一，川渝云贵的上饶后裔是天然的高价值用户池 |

### 7.2 县域复制的标准化包

把广信区的打法封装成可交付的"县域包"：

1. **工具包**：小程序（多县域多租户）、采集 SOP、校对工具、PDF 排版模板
2. **培训包**：修谱师认证课程、家族大使培训课程、地推话术手册
3. **合作包**：与当地宗亲会/文化机构/档案馆的合作模板、授权书模板、分成协议模板
4. **品牌包**：统一的视觉、内容模板、活动方案（晒谱节、寻根季）

**复制模式选择**：
- **直营**：控制力强，但人力成本高，适合核心县区
- **合伙人制**：本地合伙人负责地推与关系，总部提供产品与品牌，收入分成（推荐，这是本项目最适合的扩张方式，因为**谱源获取高度依赖本地关系，总部派人去外地必然低效**）
- **平台加盟**：开放给已有修谱服务商，收平台使用费

### 7.3 长期资产

三年后，本项目真正值钱的东西不是小程序，而是：

1. **上饶姓氏谱牒数据库**——一个县 100 万条人口世系关系，是全国独一份的地方文献资产
2. **家族关系网络**——350 个家族的组织触点与人脉
3. **"上饶寻根"品牌**——在本地文化领域的认知份额
4. **数据能力**——迁徙路径、姓氏分布、家族史的可视化与分析能力

这些资产的变现路径远超修谱本身：地方文旅、乡村研学、家族企业服务、乡贤返乡经济、地方志编纂、学术研究合作。

## 八、第一件事该做什么

如果只做一件事：

> **这个月内，去一趟广信区档案馆，把《清道光年间彭城堂刘氏族谱》的数字化合作谈下来。**

理由：
- 它是**馆藏**的，来源正规、有官方背书，不涉及私人持谱的信任问题
- 它**有明确的历史信息**（"由闽迁饶"、堂号、版本），可以立刻做出高质量的内容
- 它能建立**第一个政府端合作关系**，后续所有乡镇走访都有了背书
- 它是**第一个可展示的标杆**，有了它，后面 199 个家族都会好谈得多

**第一周的具体动作**：
1. 通过政府网公开渠道找到区档案馆的联系方式与主管领导
2. 准备一份 2 页的合作建议书，核心是"我们免费帮您完成馆藏族谱的数字化，成果双方共享署名"
3. 带一台平板，现场演示小程序里已经做好的家族树（哪怕是用公开数据做的 demo）
4. 争取到"扫描 1 部族谱"的最小合作承诺

从这一部族谱开始，剩下的都是时间问题。
